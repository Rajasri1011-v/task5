# task5
 Exploring Tree-Based Models in Machine Learning 

I recently worked on a project using the Heart Disease dataset to apply and compare two powerful tree-based classification techniques:

✅ Decision Tree Classifier – trained and visualized the model using Graphviz, analyzed performance across various tree depths to observe overfitting/underfitting.

✅ Random Forest Classifier – leveraged the power of ensemble learning for improved accuracy and robustness. Also explored feature importance to understand which attributes contribute most to heart disease prediction.

📊 Used Scikit-learn, Pandas, and Matplotlib to build, train, and evaluate the models using cross-validation for better generalization insights.

This project strengthened my understanding of supervised learning and the importance of model tuning and interpretation.
